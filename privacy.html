Privacy Policy

Last updated: October 25, 2026

Claude Local is a personal tool used only by its owner on the owner's own computer.

Data accessed

With the owner's consent, Claude Local accesses the owner's Google data (Gmail, Drive, Calendar, Docs, Sheets, Slides, Tasks, Contacts and Forms) only to carry out requests the owner makes.

Storage

Google sign-in tokens are stored only on the owner's computer. Claude Local runs no server and keeps no copy of Google data anywhere else.

Sharing

Claude Local does not sell, share or transfer Google user data to anyone. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account permissions.
